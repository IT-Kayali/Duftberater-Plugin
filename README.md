# Duftberater Plugin

WordPress-Plugin **SY Duftberater** für den intelligenten Duftberater von Alowidat.

**Aktueller Stand: Version 1.28.30**

Der vollständige Plugin-Quellcode liegt direkt im Repository.

## Installationsfertige ZIP

Für WordPress bitte diese Datei herunterladen und direkt unter **Plugins → Installieren → Plugin hochladen** verwenden:

[sy-duftberater-v1.28.30.zip](releases/sy-duftberater-v1.28.30.zip)

Die ZIP enthält den sauberen Plugin-Ordner `sy-duftberater/` und wurde beim automatischen Build geprüft.
